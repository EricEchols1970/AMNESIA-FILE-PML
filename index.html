The Amnesia Problem

Every AI model starts each conversation with a blank slate. No memory of prior sessions, decisions, relationships, or context.

🧠

No Persistent Memory

Every new conversation starts blank. Prior decisions, context, and relationships are lost. AI can't build on what it already learned.

🔒

Vendor Lock-In

Memory stored inside one model provider is trapped there. Switching from GPT to Claude means starting over. Your data isn't yours.

📈

Context Explosions

Stuffing full history into every prompt doesn't scale. Token costs grow linearly with history. Retrieval-based memory breaks that curve.

🏢

No Enterprise Controls

No tenant isolation. No RBAC. No audit trail. No export. Enterprise AI memory needs security architecture, not a bolt-on.

The PML Architecture

A Memory Gateway sits between clients/agents and model providers. It controls retrieval, writes, authorization, tenant isolation, and export.

Three Memory Stores

Memory lives outside the model in three complementary stores. The model retrieves only what it needs.

Structured State Store

Authoritative current state

Stores what is true now: current entity state, key-value pairs, task/project/org status.

Overwritten on state change. Previous values archived to Event Store automatically.

Schema: Document/JSON with typed fields per entity class.

Semantic Memory Store

Searchable historical knowledge

Stores conversation summaries, embeddings, historical context, and background knowledge.

Vector-indexed for semantic retrieval. Supports similarity search, keyword search, and hybrid retrieval.

Schema: Vector embeddings + metadata + original text.

Event / Milestone Store

Immutable decision log

Stores state transitions, decision records, and milestone markers.

Append-only. Never modified or deleted. Complete provenance and audit trail.

Schema: Event log with timestamp, actor, type, before/after diff, rationale.

MCP Tool Surface

Seven core tools that any MCP-compatible host can use. No custom adapters required.

memory.search
Primary retrieval (semantic + hybrid). Returns ranked chunks + optional current state. Decouples per-turn context from total history size.
memory.get_state
Fetch authoritative structured state. Lightweight. Returns current task/project/org state as small JSON object.
memory.store
Write new memory. Auto-routes to correct store based on type (fact, decision, event, state_update). Supports structured extraction.
memory.update
Correct or supersede existing memory. Maintains provenance. Supersedes, doesn't overwrite silently. Records reason for change.
memory.list
Browse and filter memories. For exploration and admin use. Supports pagination, tags, time range, and store filters.
memory.export
Full or scoped export (anti-lock-in). Documented open schema. Enables self-hosting or migration. Requires export role.
memory.delete
Scoped deletion. Requires admin role. Strongly gated by RBAC. Audit-logged. Records deletion in Event Store.

Security is Architecture, Not Marketing

Seven layers, enforced in order, on every request. Tenant isolation at the storage layer, not just the API.

1

Tenant Isolation

Every request scoped to a tenant ID. Cross-tenant access structurally impossible at storage layer.

2

Authentication

API key or OAuth 2.0 token required on every request. Failed attempts rate-limited and logged.

3

Authorization (RBAC)

Roles: admin, writer, reader, export. Policies evaluated per-request, not cached.

4

Scoped Session Credentials

Short-lived tokens (15-60 min TTL) scoped to specific operations. Revocable by admin at any time.

5

Encryption

AES-256 at rest. TLS 1.3 in transit. Per-tenant keys with rotation support.

6

Audit Trail

Every read, write, export, and admin action logged. Append-only. Immutable.

7

Key Management

Per-tenant encryption keys. KMS-backed. Rotation with zero downtime.

Bring Your Own Key (BYOK)

Default Enterprise Model

Amnesia File charges for the PML infrastructure. The customer maintains its own relationship and billing with the underlying model provider (OpenAI, Anthropic, Google, etc.).

"Amnesia File doesn't replace your AI providers. It sits above them and makes your organizational memory portable across them."

This avoids turning Amnesia File into a pass-through billing operation before the gateway economics are proven. An optional managed-routing product will be offered later where Amnesia File handles provider billing with a transparent usage margin.

Radical Transparency

HONEST SECURITY STATEMENT

Once plaintext memory is deliberately sent to an external model provider for processing, that provider can access and process that plaintext. PML does not claim to protect memory from the model provider it is sent to.

PML protects memory at rest, in transit, and from unauthorized access — but cannot control what an external provider does with plaintext it receives. This transparency is a trust feature, not a liability.
